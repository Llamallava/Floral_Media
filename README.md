# Floral Media

> **This app is currently in development.**

Floral Media is a mobile app that lets you photograph flowers and learn about them. When you take a photo, the app identifies the flower using the Plant.id API, then uses Claude AI to generate a reference entry covering the flower's cultural history, mythology, and color symbolism. That entry gets saved to a shared database so every user benefits from it the next time the same flower is photographed.

---

## What it does

The app has three sections.

### Garden

Your Garden is a personal photo log of every flower you have photographed. Tap the camera button, point at a flower, and the app handles everything else: it uploads the photo, identifies the species, checks whether the flower already exists in the database, and if not, generates a full reference entry for it before saving the photo to your garden. Each photo in the grid shows the flower's common name. Tapping a photo opens the full detail view for that flower.

### Lexicon

The Lexicon is a searchable list of every flower in the shared database. You can scroll through it, search by name, and tap any entry to read its full reference page. Each flower page has four tabs: a summary of what the flower means across cultures, mythology (religious and mythological stories), history (documented human use and historical events), and colors (what each color variant of that flower has meant in different traditions). The page also shows a gallery of reference photos when available.

The Lexicon includes a Flash Cards mode that presents each flower's summary as a prompt and lets you test yourself on the name before revealing the answer along with the mythology and history.

### Bouquet

The Bouquet tab is planned but not yet implemented.

---

## How it works

The app is built with React Native and Expo. The backend is Supabase, which handles user authentication, the flower database, photo storage, and edge functions. Plant identification runs through the Plant.id API. Flower lore is generated by Claude (claude-sonnet-4-6) via a Supabase edge function that writes the result directly to the database. Once a flower is in the database, its entry is reused for every future photo of that species rather than regenerating it.
